1. 導入

  1. ZIP をダウンロードして展開する
    デスクトップなど、書き込みできる場所に展開してください。
  2. 「メディアダウンローダー.exe」をダブルクリック
    Python などの準備は要りません。
  3. 初回だけ、部品の取得を確認されます
    「はい」を押すと必要な部品（約 90 MB）を公式の配布元から取得します。数分かかります。
2 回目以降はこの確認は出ません 取得した部品は %LOCALAPPDATA%\johukku\bin に置かれ、 次回からはそのまま起動します。 Whisper 字幕作成ツールとも共有するので、 どちらか一方で取得済みなら、もう一方では取得を省けます。

2. 画面の使い方

1. URL

保存したいページの URL を貼り付けます。 URL をコピーした状態でアプリを起動すると、自動で入力欄に入ります。 「貼り付け」ボタンでも入れられます。

2. 保存先

既定ではダウンロードフォルダです。「参照...」で変更でき、次回以降も記憶されます。 「開く」を押すと保存先をエクスプローラーで開けます。

3. 形式

動画か音声かを選びます。詳しくは次の項目を参照してください。

4. 字幕

「この URL の字幕を調べる」を押すと、その動画に用意されている字幕が一覧表示されます。 詳しくは字幕を保存するを参照してください。

ダウンロードとログ

「ダウンロード」で処理が始まり、進捗バーとログで状況が分かります。 途中でやめたいときは「中止」を押してください。

3. 形式の選び方

形式選ぶ場面
動画（最高画質）とにかく良い画質で残したいとき。ファイルは大きくなります
動画（1080p まで）迷ったらこれ。画質と容量のバランスが良い
動画（720p まで・軽い）容量を節約したいとき、内容が分かればよいとき
音声のみ（mp3）音楽やラジオとして聴くとき、文字起こしに回すとき
音声のみ（wav・無圧縮）編集する予定があるなど、音質を落としたくないとき
「最高画質」でも 4K になるとは限りません 選べる画質はそのサイトが配信しているものが上限です。 サービスによっては 1080p や 720p が最大のこともあります。

プレイリストをまとめて取得

チェックを入れると、再生リストの URL からまとめて保存します。 件数が多いと時間もディスクも消費するので、最初は外したまま 1 本試すことをおすすめします。

4. mkv になったときは

保存したファイルの拡張子が .mkv になることがあります。 これは映像と音声の組み合わせが mp4 の規格に収まらない場合の正常な動作です。 Windows 11 の標準プレイヤーではそのまま再生できます。

古い機器や編集ソフトで開きたい場合は、 「mp4 に統一する（mkv を避ける）」にチェックを入れてください。 確実に mp4 で保存される代わりに、画質が 1 段下がることがあります。 mp4 に収まる組み合わせを優先して選ぶためです。

使い分けの目安 パソコンで見るだけなら外したまま（高画質）、 スマホに移す・古いテレビで見る・編集ソフトに読み込ませるならチェックを入れる。

5. 字幕を保存する

  1. URL を入れて「この URL の字幕を調べる」を押します
  2. 用意されている字幕が一覧に出ます
  3. 保存したいものを選びます（Ctrl キーを押しながらで複数選択）
  4. 「ダウンロード」を押すと、動画と同じ場所に保存されます
種類内容
手動投稿者や有志が付けた字幕。精度が高い
自動生成サービス側が音声認識で作った字幕。精度はそれなり

形式は srt か vtt を選べます。迷ったら srt で構いません。 「字幕だけ保存する」を有効にすると、動画を落とさずに字幕だけ取得できます。

字幕が 1 つも無い動画には 「音声のみ（mp3）」で保存して、Whisper 字幕作成ツールに読み込ませると、 音声から字幕を作れます。

6. まとめて処理する

URL の入力欄に 1 行に 1 つずつ並べると、上から順番に処理します。 

https://example.com/watch/aaaa
https://example.com/watch/bbbb
https://example.com/watch/cccc

途中で「中止」を押すと、処理中のものが終わった時点で止まります。 1 本が失敗しても、残りの処理は続きます。

7. 字幕作成ツールと組み合わせる

字幕が用意されていない動画でも、この 2 つを組み合わせれば字幕を作れます。

  1. このツールで「音声のみ（mp3）」を選んで保存する
  2. Whisper 字幕作成ツールにその mp3 を読み込ませる
  3. SRT ファイルが出来上がる

どちらのツールも FFmpeg を同じ場所で共有するので、 2 本目のセットアップでは部品の取得を省けます。

8. アンインストール

展開したフォルダを削除するだけです。レジストリなどは変更していません。

初回に取得した部品と設定は下記に保存されるので、完全に消したい場合はこちらも削除してください。

C:\Users\（ユーザー名）\AppData\Local\johukku\bin
C:\Users\（ユーザー名）\AppData\Local\johukku\media-downloader

bin はWhisper 字幕作成ツールとも共有しています。 そちらを使い続ける場合は残しておいてください。
