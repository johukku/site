FAQ・困ったとき

最終更新：2026年9月

起動・導入について

「Windows によって PC が保護されました」と出る

有料の署名（デジタル証明書）を付けていないため、初回起動時に表示されます。 「詳細情報」→「実行」で起動できます。

気になる場合は、GitHub で ソースコードを公開しているので、中身を確認してからお使いください。

初回の部品取得に失敗する

ほとんどが通信エラーです。もう一度起動して、取得をやり直してください。 社内ネットワークなどで GitHub への接続が制限されている場合は、取得できないことがあります。

何度も失敗する場合は、メニューの「ヘルプ → 部品を入れ直す（FFmpeg）」で取得し直します。 FFmpeg が無くても、字幕の編集と保存はできます。

ウイルス対策ソフトに止められる

この種のツールは誤検知されることがあります。 心配な場合はソースコードをご確認ください。

編集について

動画を開いても音が出ない・波形が出ない

動画に音声が入っていない可能性があります。その場合はコマの表示だけ使えます。

音声が入っているのに出ないときは、「ヘルプ → 部品を入れ直す（FFmpeg）」で FFmpeg を取得し直すと直ることがあります。

動画の映像が動かない

仕様です。本ツールは動画そのものは再生せず、音だけを再生して、絵は「その時刻の 1 コマ」を切り出して見せます。 字幕を直すのに要るのは「いま何と言っているか」を聞くことなので、これで足ります。

おかげで動画の形式（MKV / VP9 / AV1 など）を選ばず、余計な部品も要りません。

字幕が文字化けする

文字コードは UTF-8 → UTF-16 → Shift_JIS の順に自動で判定していますが、古い形式のファイルは読み違えることがあります。 メモ帳で開いて「UTF-8」で保存し直してから開いてください。

元のファイルはどうなりますか

「保存」は開いたファイルを上書きしますが、最初の 1 回だけ「（編集前）」という控えを同じ場所に残します。 やり直したくなったら、その控えを開き直してください。

焼き込みは元の動画を書き換えず、「（動画名）_字幕入り.mp4」として別に書き出します。

時刻をぴったり合わせるコツは

「この字幕を再生」（Ctrl+Enter）で聞きながら、声が始まった瞬間に [、終わった瞬間に ] を押すのがいちばん速い方法です。 いまの再生位置がそのまま開始・終了に入ります。

細かく詰めたいときは、波形を Ctrl+ホイールで拡大して、上の帯の端をドラッグしてください。

ASS を開いたらスタイルが消えた

ASS は本文と時刻だけを読み、元のスタイルは読み捨てます。 保存すると本ツールのスタイル（焼き込みと同じ 4 種）で書き出されます。

凝ったスタイルをそのまま残したい ASS には向きません。 Whisper 字幕作成ツールが出した ASS なら、同じスタイルなので問題ありません。

Whisper 字幕作成ツールの JSON も開けますか

開けます。区間の時刻と本文を読み込みます。保存するときは SRT / WebVTT / ASS のどれかを選んでください。

YouTube の自動生成字幕を開くと同じ文が 2 回ずつ並ぶ

自動生成の VTT は「前の行の再掲」を含む独特の並びですが、本ツールはそれを外して開くので、ふつうは 2 回ずつにはなりません。 なる場合は、別のソフトを通したファイルかもしれません。 メディアダウンローダーで保存し直したものを開いてみてください。

広告

焼き込みについて

焼き込みが失敗する

グラフィックドライバが古いと、GPU での書き出しに失敗することがあります。 焼き込みの画面で「GPU が使えれば使う」のチェックを外すと、CPU で書き出します。

直らない場合は、状況を添えて運営者情報のページからご連絡ください。

字幕の文字が小さい／大きい

文字の大きさは、動画の解像度と「1 行の文字数」から自動で決まります（一番長い行が横幅に収まる大きさ）。 大きくしたいときは「自動で折り返す」で 1 行の文字数を減らしてください。 スタイルは焼き込みの画面で「見本を見る」を押して確かめられます。

そのほか

他のツールと FFmpeg を共有しますか

はい。%LOCALAPPDATA%\johukku\bin に置き、 Whisper 字幕作成ツール・メディアダウンローダー・メディアコンバーターと共有します。 どれかで取得済みなら、ほかでは取得を省けます。

削除したい（アンインストール）

フォルダの中の アンインストール.bat をダブルクリックしてください。 ツールのフォルダと設定ファイルを削除します。 共有している FFmpeg は、消すかどうかを確認します（Enter で「残す」）。

手で削除したい場合は 使い方の「9. アンインストール」をご覧ください。

Mac や Linux で使えますか

現在は Windows 用としてのみ配布しています。 音の再生に Windows の仕組みを使っているため、他の OS ではそのままでは動きません。

商用利用はできますか

できます。本ツールは MIT License で、無料で商用・業務利用も可能です。

使用する FFmpeg（GPL v3）は同梱しておらず、利用者のパソコンが公式ビルドを直接取得します。
