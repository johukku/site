配布中のもの

メディアダウンローダー

v1.0　/　2026年9月公開　/　Windows 10・11　/　インストール不要

URL を貼り付けて形式を選ぶだけで、動画や音声を手元に保存します。 Python などの準備は要らず、exe をダブルクリックするだけで使えます。

画質の選択、音声だけの抽出（mp3 / wav）、まとめて処理に対応。 その動画に用意されている字幕を一覧から選んで保存することもできます。

Whisper 字幕作成ツール

v1.1　/　2026年9月10日更新　/　Windows 10・11

動画や音声を読み込ませると、AI が話している内容を聞き取って 字幕ファイル（SRT / VTT / ASS / JSON）を作ります。 音声を外部に送信せず、すべて手元のパソコンで処理します。 NVIDIA のグラフィックボードがあれば 10 分の動画を 1〜2 分で処理できます。

日本語の字幕として実際に使える形にするところまで面倒を見ます。 1 行が長くなりすぎないよう自動で折り返し、句読点も補います。 v1.1 からは、字幕を動画そのものに焼き込んで書き出せるようになりました。
