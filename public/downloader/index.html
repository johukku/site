メディアダウンローダー

v1.1　／　2026年9月12日更新

URL を貼り付けて形式を選ぶだけで、動画や音声を手元に保存する Windows 用のソフトです。 Python などの準備は要らず、exe をダブルクリックするだけで使えます。

自分がアップロードした動画、自分の配信のアーカイブ、 権利者が保存を認めているコンテンツを手元に残しておくために作りました。

対応：Windows 10 / 11　｜　配布ファイル 約 11 MB　｜　インストール不要　｜　無料

ダウンロード（無料）

約 11 MB。初回起動時にだけ、動作に必要な部品を自動で取得します。

使ってよい範囲を確認してください

権利者に無断で公開されているものを保存する行為は、 私的使用が目的であっても違法となる場合があります。 また、多くの動画サービスは利用規約でダウンロードを禁じています。

各サービスの規約とお住まいの国の法律を確認のうえ、自己責任でご利用ください。

できること

  • URL を貼るだけ ― 形式を選んで「ダウンロード」を押すだけです。
  • 準備が要らない ― Python も追加の設定も不要。exe を実行するだけ。
  • URL の自動貼り付け ― URL をコピーした状態で起動すると、入力欄に入った状態で始まります。
  • まとめて処理 ― 1 行に 1 つずつ URL を並べると順番に処理します。途中で中止もできます。
  • 音声だけ抜き出せる ― mp3（軽い）と wav（無圧縮）を選べます。
  • 字幕を選んで保存 ― その動画に用意されている字幕を一覧表示し、選んだものだけ .srt / .vtt で保存します。
  • 字幕作成につなげられる ― 音声を抜き出してWhisper 字幕作成ツールに読み込ませれば、字幕が無い動画にも字幕を作れます。動画のまま読み込ませれば、字幕を焼き込んだ動画も作れます。
  • 削除も簡単 ― 同梱の アンインストール.bat で、設定ファイルまでまとめて削除できます。
広告

選べる形式

形式向いている用途
動画（最高画質）いちばん良い画質で残したいとき
動画（1080p まで）ファイルが大きくなりすぎるのを避けたいとき
動画（720p まで・軽い）容量を節約したいとき
音声のみ（mp3）音楽・ラジオ・文字起こし用
音声のみ（wav・無圧縮）音質を落としたくないとき

「最高画質」はそのサイトが配信している中で一番良いものを選びます。 画質の上限はサイト側の都合で決まるため、サービスによっては 1080p や 720p が上限のこともあります。

初回だけ取得される部品について

実際のダウンロード処理は yt-dlp と FFmpeg という定評あるソフトが行います。 この 2 つは配布ファイルに同梱しておらず、 初回起動時に公式の配布元から自動で取得します（約 90 MB、数分）。

同梱していないのには理由があります。

  • yt-dlp は動画サイト側の変更に合わせて頻繁に更新されます。同梱すると、配り直すまで古いままになってしまいます。
  • FFmpeg は GPL というライセンスのため、同梱して配ると配布側にソースコードの提供義務が生じます。利用者のパソコンが公式配布元から直接取得する形なら、こちらは何も再配布しません。

置き場所は %LOCALAPPDATA%\johukku\bin です。 FFmpeg はWhisper 字幕作成ツールの焼き込み機能（v1.1 以降）と共有するため、どちらかで取得済みなら、もう一方では取得を省けます。 ツールを削除するときに、消すかどうかを確認します（アンインストール）。
