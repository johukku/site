メディアコンバーター

v1.0　／　2026年9月15日公開

手元にある動画や音声を、目的に合わせて変換する Windows 用のソフトです。 Python などの準備は要らず、exe をダブルクリックするだけで使えます。

「チャットに貼ろうとしたら大きすぎて弾かれた」「スマホで撮った .mov が パソコンで開けない」——そんなときのために作りました。

いちばんの特徴は「変換せずに済むときは変換しない」ことです。 .mov や .mkv を MP4 にしたいだけなら入れ物を詰め替えるだけで済ませるので、 画質はまったく落ちず、数百 MB の動画でも数秒で終わります。

対応：Windows 10 / 11　｜　配布ファイル 約 12 MB　｜　インストール不要　｜　無料

ダウンロード（無料）

約 12 MB。初回起動時にだけ、変換に使う FFmpeg を自動で取得します。

できること

やりたいこと内容
MP4 に変換 .mov / .mkv / .webm / .avi などを、どこでも再生できる MP4 にそろえます。 中身がそのまま入れられる場合はコピーするだけです。
サイズを指定して圧縮 「25 MB に収めたい」と指定できます。音声のぶんを差し引いて映像のビットレートを決め、 2 パス（下読み → 本番）で書き出すので、指定した大きさに収まります。
音声だけ取り出す mp3 / m4a / wav から選べます。元がすでに同じ形式なら、変換せずそのまま取り出します（無劣化）。
GIF にする 色を調べてから当てる 2 段階の方式なので、よくある「色がにじんだ GIF」になりません。幅と fps を選べます。

共通のオプションとして、解像度の上限、範囲の切り出し（開始・終了）、 画質と速度の選択、まとめて処理（複数ファイルを順番に処理・途中で中止も可）があります。

広告

「変換しない」という判断について

同じ H.264 の動画でも、.mov・.mkv・.mp4 は 入れ物が違うだけで中身は同じことがよくあります。 本ツールは変換前に中身を調べ、そのまま MP4 に入れられる場合はコピーで詰め替えます。

  • 再エンコードしないので画質の劣化がゼロ
  • 数百 MB の動画でも数秒で終わる
  • 音声だけが MP4 に入れられない形式（Opus など）のときは、映像はコピーしたまま音声だけを変換します
何をするのかは、押す前に画面に出ます 「この設定なら: 映像はそのままコピーします（再エンコードなし・無劣化）」のように、 これから行う処理が変換ボタンの近くに表示されます。 作り直しになるのか、詰め替えで済むのかが分かってから実行できます。

画質と速度

選択内容
画質優先（CPU・遅い）いちばんきれいですが時間がかかります（libx264 / CRF 18 / preset slow）
バランス（おすすめ）GPU が使えれば GPU を使い、無ければ CPU（libx264 / CRF 20）
速度優先（GPU）とにかく速く。画質は少し落ちます

GPU（NVIDIA の NVENC、Intel の QSV、AMD の AMF）は、FFmpeg が対応していてもドライバの版が合わないと使えません。 本ツールは実際に 1 コマだけ試してから採用し、駄目なら自動で CPU に切り替えます。

初回だけ取得される部品について

実際の変換処理は FFmpeg という定評あるソフトが行います。 これは配布ファイルに同梱しておらず、初回起動時に公式の配布元から自動で取得します（約 73 MB、数分）。

同梱していないのは、FFmpeg が GPL というライセンスのため、同梱して配ると配布側にソースコードの提供義務が生じるからです。 利用者のパソコンが公式の配布元から直接取得する形なら、こちらは何も再配布しません。

置き場所は %LOCALAPPDATA%\johukku\bin です。 Whisper 字幕作成ツールの焼き込み機能やメディアダウンローダー・字幕エディターと共有しているので、 どれかで取得済みなら、ほかでは取得を省けます。

あわせて使う

同じ考え方で作った道具が、ほかにもあります。どれも無料で、動画を扱う部品（FFmpeg）は共有します。

  • 字幕エディター ― 字幕を直してから焼き込みたいときはこちら
